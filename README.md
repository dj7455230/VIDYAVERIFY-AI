# VIDYAVERIFY AI

> Verify Every Record. Build Trusted Education.

**APAAR ID-Based Student Data Management and Verification Platform** for AICTE-Approved Institutions.

Built for the Smart India Hackathon (SIH26263).

---

## ⚠️ Demonstration Notice

This is a **prototype** using **synthetic, fictional data only**. No real APAAR IDs, Aadhaar numbers, or institutional records are stored, verified, or transmitted. All data is generated by a deterministic seed script. The verification provider is a clearly-labelled `DEMO_SIMULATOR`, not a connection to any official system.

## Quick Start

### Prerequisites

- Python 3.12+
- Node.js 20+ (v24 tested)
- PostgreSQL 14+ (v18 tested)
- `uv` (Python package manager) or `pip`

### 1. Database Setup

```bash
# If PostgreSQL is running locally, create the database:
/Library/PostgreSQL/18/bin/psql -U postgres -h 127.0.0.1
# In psql:
# CREATE DATABASE vidyaverify;
# CREATE USER vidyaverify_user WITH PASSWORD 'vidyaverify_pass_2026';
# GRANT ALL PRIVILEGES ON DATABASE vidyaverify TO vidyaverify_user;
# ALTER DATABASE vidyaverify OWNER TO vidyaverify_user;
```

### 2. Backend Setup

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Copy environment
cp ../.env.example ../.env

# Run migrations
alembic upgrade head

# Seed synthetic data
python -m scripts.seed_demo_data

# Start backend
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 4. Access the Application

- Frontend: http://localhost:3000
- API docs: http://localhost:8000/docs
- Health check: http://localhost:8000/api/v1/health
